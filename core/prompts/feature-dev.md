# Prompt 模板：功能开发

> 使用本模板向 AI 下达功能开发指令，确保 AI 获得充足的上下文。

---

## 模板

```
## 任务
[简要描述要实现的功能]

## 背景
[为什么需要这个功能？解决什么问题？]

## 需求详情
- [具体需求点 1]
- [具体需求点 2]
- [具体需求点 3]

## 技术约束
- 目标模块：[模块路径]
- 相关模块：[列出可能涉及的其他模块]
- 使用模式：[参考哪个既定模式]

## 验收标准
- [ ] [可验证的标准 1]
- [ ] [可验证的标准 2]
- [ ] [测试覆盖要求]

## 非目标
- [明确不需要做的事情]
```
