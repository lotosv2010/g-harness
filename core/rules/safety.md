# 安全硬性规则

> AI 在任何情况下都必须遵守的安全规则。
> 适用于所有技术栈和项目类型。

---

## S001：敏感信息保护

- 禁止读取、输出、复制 `.env*` 文件内容
- 禁止在代码中硬编码密钥、Token、密码、私钥
- 禁止在日志中输出敏感信息
- 发现代码中存在硬编码密钥时，必须立即报告

## S002：破坏性操作确认

以下操作必须先获得用户明确确认：
- 删除文件或目录（`rm`、`unlink`）
- 重置 Git 状态（`git reset --hard`、`git checkout .`）
- 修改数据库结构（migration）
- 批量修改文件
- 修改 CI/CD 配置
- 发布包到 npm / PyPI 等仓库

## S003：Git 操作限制

- 禁止自行执行 `git commit`、`git push`（除非用户明确要求）
- 禁止 `git push --force` 到主分支
- 禁止使用 `--no-verify` 跳过钩子
- 禁止修改 `.gitignore` 移除安全相关条目

## S004：第三方依赖

- 新增依赖前必须说明理由
- 优先使用已有依赖解决问题，避免引入功能重叠的新包
- 禁止安装来源不明的包
- 全局安装必须确认

## S005：网络请求

- 禁止向非项目相关的外部服务发送数据
- 禁止在未说明的情况下调用生产环境 API
- API 密钥和认证信息通过环境变量提供
