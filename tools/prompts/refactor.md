# Prompt 模板：重构请求

> 使用本模板请求 AI 进行代码重构。

---

## 模板

```
## 重构请求

### 目标
[这次重构要达成什么目的]

### 目标文件/模块
- [文件路径或模块]

### 重构类型
- [ ] 提取函数/组件
- [ ] 消除重复代码
- [ ] 模块重组（符合功能模块结构）
- [ ] 性能优化
- [ ] 类型系统改进
- [ ] 依赖解耦

### 约束
- 行为不变：[哪些行为必须保持不变]
- 兼容性：[需要兼容什么]
- 分步进行：[是否需要分多次 PR]

### 验证方式
[如何确认重构没有引入问题]
```

## 快捷用法

```
请将 packages/web/src/components/ 下的用户相关组件
重构到 packages/web/src/features/user/ 功能模块结构中。
遵循 .claude/protocols/refactor.md 的流程。
分步进行，每步确认测试通过。
```
