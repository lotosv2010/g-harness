# Prompt 模板：功能开发

> 使用本模板向 AI 下达功能开发指令，确保 AI 获得充足的上下文。

---

## 模板

```
## 任务
[简要描述要实现的功能]

## 背景
[为什么需要这个功能？解决什么问题？]

## 需求详情
- [具体需求点 1]
- [具体需求点 2]
- [具体需求点 3]

## 技术约束
- 目标模块：[packages/web/src/features/xxx]
- 相关模块：[列出可能涉及的其他模块]
- 使用模式：[参考 docs/patterns/ 中的哪个模式]

## 验收标准
- [ ] [可验证的标准 1]
- [ ] [可验证的标准 2]
- [ ] [测试覆盖要求]

## 非目标
- [明确不需要做的事情]
```

## 使用示例

```
## 任务
实现用户认证模块的登录功能

## 背景
用户需要通过邮箱密码登录系统，这是 MVP 阶段的核心功能。

## 需求详情
- 邮箱密码登录表单
- 表单校验（邮箱格式、密码最少 8 位）
- 登录 API 调用和错误处理
- 登录成功后跳转到首页
- 登录状态持久化（token 存储）

## 技术约束
- 目标模块：packages/web/src/features/auth
- 相关模块：packages/web/src/api（新增登录端点）
- 使用模式：参考 docs/patterns/form-management.md

## 验收标准
- [ ] 表单校验正确拦截无效输入
- [ ] 登录成功后正确存储 token 并跳转
- [ ] 登录失败显示明确的错误提示
- [ ] 单元测试覆盖核心逻辑
- [ ] 组件测试覆盖用户交互

## 非目标
- 注册功能（另一个任务）
- OAuth / 社交登录（后续迭代）
- 记住密码功能（后续迭代）
```
