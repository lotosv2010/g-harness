# Prompt 模板：Bug 报告

> 使用本模板向 AI 报告 Bug，确保 AI 有足够信息定位问题。

---

## 模板

```
## Bug 报告

### 现象
[描述 Bug 的具体表现]

### 复现步骤
1. [步骤 1]
2. [步骤 2]
3. [步骤 3]

### 期望行为
[应该怎样]

### 实际行为
[实际怎样]

### 错误信息
```
[粘贴错误日志或截图路径]
```

### 影响范围
- 环境：[开发 / 测试 / 生产]
- 频率：[必现 / 偶现]
- 影响用户：[所有用户 / 特定条件]

### 可能的相关文件
- [文件路径 1]
- [文件路径 2]
```
