# Prompt 模板：代码审查

> 使用本模板请求 AI 对代码进行结构化审查。

---

## 模板

```
## 审查请求

请审查以下变更：

### 变更文件
- [文件路径 1]
- [文件路径 2]

### 变更目的
[这次变更要实现什么]

### 关注重点
- [ ] 正确性
- [ ] 架构合规（模块边界、依赖方向）
- [ ] 代码质量（命名、复杂度、重复）
- [ ] 测试覆盖
- [ ] 安全性
- [ ] 性能

### 上下文
[任何有助于理解变更的背景信息]

请按照 .claude/protocols/review.md 的格式输出审查结果。
```

## 快捷用法

```
请审查 packages/web/src/features/auth/ 目录下的所有文件。
重点关注架构合规和测试覆盖。
```
