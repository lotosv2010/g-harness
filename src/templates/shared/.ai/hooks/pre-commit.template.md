# 提交前钩子 — {{project_name}}

> 触发时机：执行 git commit 前自动检查。

---

## 检查项（阻塞提交）

1. **类型检查** — 编译通过
2. **Lint** — 无 error
3. **测试** — 相关测试通过
4. **敏感信息** — 无硬编码密钥/Token

## 检查项（警告）

5. **文件大小** — 无超过 300 行的新文件
6. **Commit 格式** — 符合 Conventional Commits
7. **文档同步** — 变更涉及的规范文档已更新

## 失败处理

- 阻塞项失败：拒绝提交，输出修复建议
- 警告项失败：允许提交，输出提醒
