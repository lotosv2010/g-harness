# 合并前钩子 — {{project_name}}

> 触发时机：PR/MR 合并到主分支前自动检查。

---

## 检查项

1. **CI 状态** — 所有 CI 检查通过
2. **Review 状态** — 至少一人 Approved
3. **冲突检查** — 无合并冲突
4. **分支同步** — 与 main 无过大偏离（>50 commits 警告）

## 自动执行

- 确认 PR 描述完整（摘要 + 变更清单 + 测试计划）
- 检查是否有未解决的 Review 评论
- 验证目标分支保护规则

## 失败处理

- 任一检查失败：阻止合并，输出原因
- 建议修复步骤
