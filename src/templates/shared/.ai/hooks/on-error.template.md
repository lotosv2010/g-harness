# 错误发生时钩子 — {{project_name}}

> 触发时机：AI 执行过程中遇到未预期错误时自动触发。

---

## 自动执行项

1. **错误收集**
   - 记录错误信息和堆栈
   - 记录触发操作和上下文
   - 记录当前工作状态

2. **影响评估**
   - 判断错误是否影响已有文件
   - 检查是否有未保存的变更丢失
   - 评估是否需要回退操作

3. **恢复建议**
   - 如果是构建错误：建议修复方向
   - 如果是文件操作错误：检查权限/路径
   - 如果是网络错误：建议重试或离线模式

## 输出

```
⚠ 错误发生：
  类型：[错误类型]
  位置：[文件:行号]
  影响：[已有文件安全/可能需要恢复]
  建议：[下一步操作]
```

## 约束

- 错误钩子本身不得抛出异常
- 不自动执行修复操作（仅建议）
- 保留完整错误日志供后续诊断
