# 安全硬性规则 — {{project_name}}

> 不可违反。违反即视为事故。

---

## S001：敏感信息保护

- 禁止读取、输出、复制 `.env*` 文件内容
- 禁止在代码中硬编码密钥、Token、密码、私钥
- 日志输出前必须脱敏（Authorization / Cookie / 身份证 / 手机号）

## S002：破坏性操作确认

以下操作必须先获得用户明确确认：
- 删除文件或目录
- 重置 Git 状态（reset --hard、clean -fd）
- 批量修改已有文件
- 发布包到 npm / 推送到生产分支

## S003：Git 操作限制

- 禁止自行执行 `git commit`、`git push`（除非用户明确要求）
- 禁止 `git push --force` 到 main / master
- 禁止使用 `--no-verify` 跳过 hook

## S004：第三方依赖

- 新增依赖必须说明理由与安全审查结论
- 优先使用已有依赖解决问题
- 禁止安装来源不明或长期无维护的包
