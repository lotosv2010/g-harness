# Bug 修复协议 — {{project_name}}

> 修复缺陷时必须遵循的执行协议。

---

## 1. 复现

- 明确复现步骤、预期行为、实际行为
- 如必要，在本地稳定复现后再动手改
- 收集日志 / 堆栈 / 截图作为证据

## 2. 定位

- 从最近 PR 与 `git log` 推断可疑变更
- 检查 `docs/decisions/` 是否有相关 ADR
- 优先修根因，不要在调用方打补丁

## 3. 修复

- 先写一个能重现 bug 的测试用例（红）
- 再写修复代码让测试变绿
- 评估是否需要同步修复其它调用点
