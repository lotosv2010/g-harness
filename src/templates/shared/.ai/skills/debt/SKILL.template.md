# 技术债扫描（debt）

识别项目中的技术债务并按 ROI 排序输出清理建议。

## 用法

```
/debt
```

## 扫描项

### 1. 代码标记
- `TODO` — 待办事项
- `FIXME` — 已知问题
- `HACK` / `WORKAROUND` — 临时方案
- `@deprecated` — 废弃代码

### 2. 复杂度超标
- 文件行数 >200
- 函数行数 >30
- 圈复杂度 >10

### 3. 依赖问题
- 过期依赖（大版本落后 ≥2）
- 已知漏洞
- 废弃包

### 4. 测试缺口
- 公共模块无测试
- 覆盖率低于阈值

## 输出格式

```
# 技术债清单

| 优先级 | 类型 | 位置 | 描述 | 预估工作量 |
|--------|------|------|------|-----------|
| P1 | 安全 | ... | ... | S |
| P2 | 复杂度 | ... | ... | M |
```

## 约束

- 只读扫描，不修改文件
- 按 ROI（影响/工作量）排序
- 标注每项技术债的风险等级
