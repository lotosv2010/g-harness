# 架构分析（analyze）

评估项目架构健康度，输出分级报告。

## 用法

```
/analyze
```

## 检查维度

### 1. 模块边界
- 是否有跨层引用
- 循环依赖检测
- 公共 API 表面积是否过大

### 2. 代码复杂度
- 超限文件（>300 行）
- 超限函数（>40 行）
- 过深嵌套（>4 层）

### 3. 测试覆盖
- 无测试的公共模块
- 关键路径覆盖率
- 测试与源码比例

### 4. 依赖健康
- 废弃依赖
- 已知漏洞
- 未使用依赖

### 5. 文档同步
- 规范文件是否与代码一致
- 过期的 TODO/FIXME

## 输出格式

```
# 架构健康报告

## 总评: [A/B/C/D/F]

### 🟢 健康 (N)
- ...

### 🟡 警告 (N)
- ...

### 🔴 问题 (N)
- ...

### 建议优先修复
1. ...
```

## 约束

- 只读分析，不修改文件
- 基于事实（文件扫描），不猜测
