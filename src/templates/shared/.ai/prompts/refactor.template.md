# Prompt：重构请求

> 请求 AI 助手对代码进行重构时使用。

---

## 模板

```
## 重构请求

### 目标
[这次重构要达成什么目的]

### 目标文件/模块
- {{source_dir}}/[模块名]/

### 重构类型
- [ ] 提取函数/模块
- [ ] 消除重复代码
- [ ] 模块重组
- [ ] 性能优化
- [ ] 类型系统改进
- [ ] 依赖解耦

### 约束
- 行为不变：[哪些行为必须保持不变]
- 测试：所有现有测试必须通过
- 分步进行：[是否需要分步执行]

### 验证方式
- 类型检查通过
- 全部测试通过
- Lint 通过
```
