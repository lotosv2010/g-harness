# 重构协议

> 当用户请求"重构"、"优化代码"、"清理"时，遵循本协议。
> 每个阶段完成后，在回复中标记 `[✓ 阶段N]`，Stop hook 会验证是否遗漏。

---

## 检查清单

### 阶段 1：评估
- [ ] 理解重构目标（性能？可读性？架构对齐？）
- [ ] 阅读相关上下文文件和 ADR
- [ ] 评估影响范围
- [ ] 确认现有测试覆盖率
- [ ] 输出风险评估

**完成标志：** `[✓ 阶段1-评估]`

### 阶段 2：方案确认
- [ ] 提出分步重构计划（每步可独立验证）
- [ ] 每步说明"改什么"、"为什么"、"如何验证"
- [ ] 等待用户确认

**完成标志：** `[✓ 阶段2-方案确认]`

**原则：** 行为不变、分步进行、测试先行

### 阶段 3：逐步执行
- [ ] 执行变更
- [ ] 每步运行测试确认行为不变
- [ ] 报告进度

**完成标志：** `[✓ 阶段3-执行]`

**禁止：** 一次性大范围修改、偷偷加入新功能、修改测试来适配重构

### 阶段 4：验证
- [ ] 全量测试通过
- [ ] 类型检查通过
- [ ] 代码检查通过
- [ ] 前后对比说明（改善了什么）

**完成标志：** `[✓ 阶段4-验证]`
