# Bug 修复协议

> 当用户报告"Bug"、"出错"、"不工作"、"异常"时，遵循本协议。
> 每个阶段完成后，在回复中标记 `[✓ 阶段N]`，Stop hook 会验证是否遗漏。

---

## 检查清单

### 阶段 1：复现与定位
- [ ] 确认 Bug 具体表现（错误信息、复现步骤）
- [ ] 定位问题代码（使用搜索工具查找）
- [ ] 分析根因（非表面症状）
- [ ] 检查相关测试用例

**完成标志：** `[✓ 阶段1-定位]`

### 阶段 2：修复方案
- [ ] 提出修复方案
- [ ] 评估影响范围
- [ ] 说明是否需要数据迁移或配置变更

**完成标志：** `[✓ 阶段2-方案]`

**原则：** 最小修改、不夹带重构、不改变无关代码行为

### 阶段 3：修复 + 回归测试
- [ ] 编写回归测试（先复现 Bug）
- [ ] 应用修复
- [ ] 确认回归测试通过
- [ ] 确认现有测试不受影响

**完成标志：** `[✓ 阶段3-修复]`

### 阶段 4：验证
- [ ] 运行完整测试套件
- [ ] 类型检查通过
- [ ] 代码检查通过
- [ ] 输出修复摘要（根因 + 回归测试说明）

**完成标志：** `[✓ 阶段4-验证]`
