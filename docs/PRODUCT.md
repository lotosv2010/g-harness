# 产品范围与边界

> 定义本项目的产品目标、用户画像、功能范围和明确的非目标。
> AI 在做任何功能决策前必须参考本文件。

---

## 产品定位

G-Forge 是一套**面向 AI 编程助手优化的前端工程化规范框架**，为开发团队提供：

1. **结构化上下文** — 让 AI 快速理解任何项目
2. **自动化约束** — 阻止 AI 生成不合规代码
3. **标准化工作流** — 让团队 AI 协作方式一致
4. **渐进式迁移** — 新老项目无痛接入

## 目标用户

| 用户画像 | 需求 |
|----------|------|
| 全栈团队 Leader | 统一团队 AI 开发规范，降低代码审查成本 |
| 前端架构师 | 在 AI 协作场景下维持架构完整性 |
| 独立开发者 | 快速搭建符合最佳实践的项目结构 |
| AI 工具开发者 | 参考或集成 G-Forge 规范到自己的工具链 |

## 功能范围（IN-SCOPE）

### P0 — 核心功能
- [ ] 项目初始化（`gforge init`）
- [ ] CLAUDE.md 层级自动生成与同步
- [ ] 架构规则引擎（解析 YAML 规则 → 校验代码）
- [ ] 代码模板系统（Handlebars 模板 → 生成代码）
- [ ] Claude Code 钩子集成

### P1 — 重要功能
- [ ] 框架预设系统（React/Vue/Next.js）
- [ ] 已有项目扫描与分析
- [ ] 渐进式迁移命令（`gforge migrate`）
- [ ] ADR 管理命令

### P2 — 增强功能
- [ ] 自定义规则开发 API
- [ ] VS Code / JetBrains 插件
- [ ] 团队规范共享与分发
- [ ] 规则违规统计仪表盘

## 非目标（OUT-OF-SCOPE）

以下内容明确不在 G-Forge 范围内：

- **不是** UI 组件库 — 不提供现成的 UI 组件
- **不是** 构建工具 — 不替代 Vite / Webpack / Turbo
- **不是** CI/CD 系统 — 不管理部署流水线
- **不是** 代码编辑器 — 不替代 VS Code / Claude Code
- **不是** Linter — 不替代 ESLint / Prettier，而是补充它们
- **不是** 全栈框架 — 不包含路由、ORM、认证等运行时功能

## 成功指标

| 指标 | 目标 |
|------|------|
| 初始化耗时 | 新项目 < 30 秒，已有项目 < 5 分钟 |
| AI 代码合规率 | 使用 G-Forge 后架构违规降低 80% |
| 采纳成本 | 第 1 天即可体验价值（仅添加 CLAUDE.md） |
| 框架覆盖 | 支持 React、Vue、Next.js 三大框架预设 |
