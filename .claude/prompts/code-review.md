## 模板

```
## 审查请求

请审查以下变更：

### 变更文件
- [文件路径 1]
- [文件路径 2]

### 变更目的
[这次变更要实现什么]

### 关注重点
- [ ] 正确性
- [ ] 架构合规（遵循 .claude/rules/ 中的规则）
- [ ] 代码质量（命名、复杂度、重复）
- [ ] 测试覆盖
- [ ] src/templates/ 技术栈无关性（如涉及模板文件）
- [ ] 安全性（密钥、敏感信息）

### 上下文
[任何有助于理解变更的背景信息]
```
