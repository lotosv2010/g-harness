# 错误发生时钩子（g-harness 项目自身）

> 触发时机：AI 执行过程中遇到未预期错误。

---

## 自动执行项

1. **错误收集**
   - 记录错误信息和堆栈
   - 记录触发操作和当前文件上下文
   - 确认是编译错误、测试失败还是运行时异常

2. **影响评估**
   - 检查 `src/templates/` 是否被意外修改
   - 确认 `pnpm-lock.yaml` 是否被改动
   - 评估是否需要 `git checkout -- <file>` 恢复

3. **恢复建议**
   - 编译错误：指出具体类型问题
   - 测试失败：指出失败用例和断言
   - 模板损坏：建议从 git 恢复

## 约束

- 不自动执行恢复操作（仅建议）
- 不删除文件或执行 git reset
