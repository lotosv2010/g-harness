## 3. 接口定义

### 通用规范

**请求头**：
```
Authorization: Bearer {token}
Content-Type: application/json
X-Request-Id: {uuid}   // 链路追踪
```

**通用响应结构**：
```json
{
  "code": 0,            // 0=成功，非0=错误码
  "message": "success",
  "data": {},
  "requestId": "xxx"
}
```

**错误码规范**：
| 错误码 | HTTP 状态码 | 说明 |
|--------|-------------|------|
| 0      | 200         | 成功 |
| 400001 | 400         | 参数错误 |
| 401001 | 401         | 未授权 |
| 403001 | 403         | 无权限 |
| 404001 | 404         | 资源不存在 |
| 500001 | 500         | 服务内部错误 |

## 6. 变更兼容性

| 变更类型 | 说明 | 是否兼容 |
|----------|------|----------|
| 新增字段 | response 中增加可选字段 | ✅ 兼容 |
| 删除字段 | 删除 response 字段 | ❌ 破坏性 |
| 修改字段类型 | string → int | ❌ 破坏性 |
| 新增必填参数 | 新增 required body 字段 | ❌ 破坏性 |

破坏性变更必须升版本号（v1 → v2）并保留旧版本至少 3 个月。
