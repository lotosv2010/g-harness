# 安全硬性规则（g-forge 项目自身）

> 开发 g-forge 时 AI 必须遵守的安全规则。
> 目标项目的安全规则见 `core/rules/safety.md`。

---

## S001：敏感信息保护

- 禁止读取、输出、复制 `.env*` 文件内容
- 禁止在代码中硬编码密钥、Token、密码、私钥
- 禁止在日志中输出敏感信息

## S002：破坏性操作确认

以下操作必须先获得用户明确确认：
- 删除文件或目录
- 重置 Git 状态
- 批量修改文件
- 发布包到 npm

## S003：Git 操作限制

- 禁止自行执行 `git commit`、`git push`（除非用户明确要求）
- 禁止 `git push --force` 到 main 分支
- 禁止使用 `--no-verify` 跳过钩子

## S004：第三方依赖

- 新增依赖前必须说明理由
- 优先使用已有依赖解决问题
- 禁止安装来源不明的包
